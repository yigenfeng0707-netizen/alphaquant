# AlphaQuant · OBS 人工录屏替代方案（约 3 分钟）

当 Playwright / edge-tts / ffmpeg 流水线失败时使用。口播与按钮以 `docs/demo-script.md` 为准。

## 缺什么时改用本方案

- 本机没有可用的 Chromium 录屏、TTS 或 ffmpeg
- 自动流水线中途超时、选择器失败
- 需要真人出镜/真人旁白（决赛现场更自然）

## 录制设置

- 画布 1920×1080，30fps，窗口采集浏览器（不要采整个桌面通知）
- 浏览器打开 **http://localhost:3000**（不要用 127.0.0.1 开前端）
- 左下角数据源 = **离线演示（可断网）**
- 先 Ctrl+F5；隐藏书签栏
- 旁白可现场说，或后期按分镜贴 `demo.storyboard.json` 的 narration

## 时间轴（对齐 8 段分镜）

| 段 | 时长 | 操作 | 口播要点 |
|----|------|------|----------|
| 片头 | 12s | 可用 `assets/demo/intro-card.png` 全屏 | 可运行产品；非实盘；未接大模型 |
| 仪表盘 | 24s | **一键演示案例 1** | 10 万；夏普 0.20 vs -0.07 是样本内模拟 |
| 选股 | 26s | **选股** → **刷新选股** | 12 因子、IC/IR、衰减告警 |
| 回测+组合 | 28s | **运行回测** → **优化入选篮子** → **加载 Brinson 归因** | 四策略；配置/选择 |
| 适当性 | 26s | **填入保守示例** → **提交问卷并匹配** | 拦截是功能 |
| 风控 | 24s | **评估风险平价组合** | VaR 非监管报备 |
| 案例2 | 26s | **运行案例 2 批量回测** → **生成并导出风控报告** | 1 亿=名义本金 |
| 片尾 | 12s | `assets/demo/outro-card.png` | 断网可复现；谢谢 |

导出：`docs/demo/AlphaQuant-演示-YYYYMMDD.mp4`，再复制进 `delivery/04_视频/`。

## 10 秒故障切备

案例 1 转圈超过 8 秒：切预先截好的仪表盘静帧（`assets/demo/kpi-still.png`），口播「同一离线样本回放」。
