# AlphaQuant 3 分钟精简演示脚本

用途：初赛快速切录或应急回放。按当前 UI 真实按钮名。总时长 3 分钟（初赛正式演示用完整版 `docs/demo-script.md`，本脚本是压缩备用）。

前置：`.\scripts\dev.ps1` 已启动；浏览器 http://localhost:3000；数据源 = 离线演示（可断网）。Ctrl+F5 一次。

## 逐步操作

| 时间 | 操作 | 口播 |
|------|------|------|
| 0:00 | 打开仪表盘 | AlphaQuant 是因子增强选股加风险平价配置的演示平台。不是实盘交易。 |
| 0:10 | 点 **一键演示案例 1** | 个人 10 万元场景：多因子选股 → 风险平价加权 → VaR 风控。 |
| 0:50 | 指向「风险平价夏普 vs 等权夏普」 | 样本内历史模拟，数字当场看，不是收益承诺。 |
| 1:10 | 侧栏点 **选股** | 十二因子、IC/IR 动态权重、衰减告警。 |
| 1:30 | 点 **组合** → **优化入选篮子** | 四种优化方法，可开关行业中性约束。 |
| 1:50 | 点 **风控** → **评估风险平价组合** | 历史/参数/蒙特卡洛三种 VaR 并排。 |
| 2:10 | 点 **适当性** → **填入保守示例** → 提交 | 保守档对满仓会拦截——这是功能不是故障。 |
| 2:30 | 点 **填入平衡示例** 再提交 | 平衡档通常通过。审计只留答案摘要，无证件号。 |
| 2:50 | 回仪表盘 | 全链路本机运行，断网可演示。未接大模型，未接支付。 |

## 应急

- 案例转圈 >8s：切预先录屏，口播「同一离线样本回放」。
- 图表空白：Ctrl+F5 后重点主按钮。
- 后端挂：http://127.0.0.1:8010/health 查看，重跑 dev.ps1。
- 适当性拦截误判为崩溃：说「这是匹配拦截，下面改平衡示例」。
