## 一、项目简介

### 1.1 项目背景

个人与小型机构对专业资产配置工具有需求，但常见痛点仍在：专业终端年费高、量化流程需要编程、风控停留在单一指标。AlphaQuant 针对「能在浏览器里走完选股—回测—组合—风控」这一层，而不是宣称已经服务百万用户。

### 1.2 解决方案（已交付 vs 规划）

**当前已交付（可现场点开）：**

1. Web 操作，无需编程即可跑通案例 1。  
2. 开源技术栈本地启动（FastAPI + Vue 3 + ECharts）。  
3. 多因子选股、四策略回测、四种组合优化、VaR/CVaR 与压力测试。  
4. 投资适当性演示：问卷分档 + 与风险平价/仓位/波动匹配 + 本地审计。  
5. 案例 2 演示：批量回测 API、Brinson 归因、标准化风控报告（JSON，可导出 md/html）。

**规划中、产品里不得写成已完成：**

- 自然语言策略生成 / 接入大模型（申报书第三阶段，2027 年 1–6 月）。  
- SaaS 订阅收费、10 万注册、年收入 500 万。  
- 基金、债券等多资产扩展（第二阶段）。

### 1.3 项目目标

| 期限 | 目标 | 状态（2026-09-10） |
|------|------|-------------------|
| 短期 | 完成核心引擎，支持 A 股演示（含离线降级） | **进行中**：A 股 12 只公开样本 + 离线合成面板可演示 |
| 中期 | 扩展至基金、债券 | 未做 |

## 四、创新点（与产品对齐）

1. **因子增强选股**：多因子 + 截面标准化 + IC/IR 动态加权 + 衰减告警。已实现。  
2. **风险平价组合**：等风险贡献，SciPy 优化；可与等权对比。已实现。  
3. **全链路**：选股 → 回测 → 组合 → 风控同一套引擎。已实现。  
4. **压力测试预警**：VaR/CVaR + 历史极端窗口 / 情景冲击。已实现（演示口径，非监管报备）。  
5. **投资适当性管理**：问卷 + 风险分档 + 产品匹配 + 本地审计日志。**本轮已做成可演示功能，不是占位。** 仍不是持牌合规系统。

产品形态：浏览器使用、参数可视化、ECharts 展示。SaaS 收费与开源社区运营属于模式规划。

## 六、市场与应用

目标用户画像：个人投资者、管理规模 1–10 亿元的小型私募研究团队、财富管理机构。  
商业模式扫描件中的定价（专业版 99 元/月等）是**设想**，产品未接支付。

### 案例 1（已可演示）

持有 10 万元闲置资金：因子选股 → 风险平价 → VaR/压力测试。  
离线样本当场数字（仪表盘两位小数，2026-09-10 API）：**风险平价夏普 0.20**，**等权夏普 -0.07**；10 万名义本金样本内期末约 ¥103,741 vs ¥95,976；日度 95% VaR 约 1.40%。  
**这是样本内历史模拟，不是收益承诺，也不是实盘成交。**

### 案例 2（已可演示，口径要诚实）

场景：小型私募需要可复现的因子研究与组合流程。  
使用：调用 REST 批量回测，Brinson 解释超额，导出标准化风控报告。  
1 亿元是**演示名义本金**，UI 已标明，**不是实盘资产管理规模。**  
离线样本 Brinson（相对等权）：配置 4.65%、选择 3.16%、交互 -1.65%、超额 6.15%，数字可对账。
