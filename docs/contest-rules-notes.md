## 参赛硬门槛（通知正文，非黄浦细则）

- 对象：长三角三省一市工程技术/项目管理/成果转化人员；个人或团队。
- 项目：**正处于研发、生产过程中的创新型项目，或已进入市场化运营和推广的创业型项目**（附件1细则以官网附件为准，本轮未下载到附件 PDF 全文）。
- 金融科技赛道范围：应用技术研究、产品研发、服务运营、跟踪评价等。
- 申报渠道：https://www.rsj.sh.gov.cn/zqncyds/ 提交申报书及相关材料；推荐通道需项目推荐表，自荐由大赛办公室审核资格。

**未在公开通知中写明的初赛硬门槛（未知项）：**

1. 黄浦初赛精确日期、地点、是材料评审还是现场路演。
2. 是否强制公网 Demo、演示视频、PPT 页数、BP 是否需更新。
3. 初赛评分表与权重。
4. 是否要求现场联网；断网演示是否被接受。

因此本轮策略：**未公开，按「可现场点开的产品 + 申报书承诺的引擎能力」准备**；**不把「无公网 Demo 就不能初赛」当成已证实规则**，故本轮不部署魔搭、不消耗创空间 Token。若黄浦通知突然要求公网链接，再补部署说明。
