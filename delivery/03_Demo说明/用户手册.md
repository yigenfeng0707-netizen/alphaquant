# AlphaQuant 用户手册（本地演示）

适用版本：本仓库当前 FastAPI + Vue 演示（`0.2.0-p1`）。**无需登录、无测试账号、无密码。** 不要把本手册里的数字当成实盘或收益承诺。

## 1. 启动

Windows PowerShell，在仓库根目录：

```powershell
.\scripts\dev.ps1
```

浏览器打开 **http://localhost:3000**（不要用 `127.0.0.1` 打开前端，以免和 Vite 主机不一致）。

OpenAPI：http://127.0.0.1:8010/docs

左侧「数据源」默认 **离线演示（可断网）**。评委电脑无网时保持离线。

## 2. 页面与按钮

| 页面 | 主按钮 | 会看到什么 |
|------|--------|------------|
| 仪表盘 | **一键演示案例 1** | 10 万名义本金、风险平价 vs 等权净值、入选标的、VaR |
| 选股 | **刷新选股** | ≥10 因子、IC/IR 权重、衰减告警、股票池评分 |
| 回测 | **运行回测** | 四策略六指标净值；**打开案例 2 / 归因报告** |
| 组合 | **优化入选篮子** / **加载 Brinson 归因** | 四方法权重饼图 + 配置/选择/交互 |
| 风控 | **评估风险平价组合** | VaR/CVaR、压力情景；**打开适当性问卷** |
| 适当性 | **提交问卷并匹配** | 分档、通过/警告/拦截、本地审计摘要 |
| 案例2 | **运行案例 2 批量回测** / **生成并导出风控报告** | 1 亿名义本金（演示口径）、批量回测、Brinson、报告 |

## 3. 案例 1（个人场景）

1. 打开仪表盘（进入后会自动跑一次）。
2. 点 **一键演示案例 1**。
3. 口述：闲置 10 万元 → 因子选股 → 风险平价 → VaR/压力测试；夏普对比是**样本内历史模拟**。

## 4. 适当性

1. 打开 **适当性**。
2. 可点 **填入平衡示例**（通常通过）或 **填入保守示例**（对风险平价满仓通常**拦截**）。
3. 选择拟匹配方法（默认风险平价），点 **提交问卷并匹配**。
4. 拦截时不要继续假装产品适合；审计表只记录时间、答案摘要、匹配结果。

## 5. 案例 2（机构演示口径）

1. 打开 **案例2**。
2. 点 **运行案例 2 批量回测**。
3. 点 **生成并导出风控报告**，文本写入 `data/reports/`。
4. 口播必须说清：**1 亿元是名义演示本金，不是已管理 1 亿实盘。**

## 6. 断网

保持数据源为离线。`data/offline/` 是合成演示面板，不是交易所行情。

## 7. 不做的事

不下单、不接券商柜台、不把回测当承诺、不把演示数据当实盘、不填写身份证进本系统。
