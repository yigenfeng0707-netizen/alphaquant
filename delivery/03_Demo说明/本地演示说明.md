# AlphaQuant 本地演示说明

无需登录、无测试账号。

```powershell
cd <仓库根目录>
.\scripts\dev.ps1
```

浏览器打开 **http://localhost:3000**。左下角数据源选 **离线演示（可断网）**。

主路径：仪表盘 **一键演示案例 1** → 选股 **刷新选股** → 回测 **运行回测** → 组合 **优化入选篮子** / **加载 Brinson 归因** → 风控 **评估风险平价组合** → 适当性 **填入保守示例** / **提交问卷并匹配** → 案例2 **运行案例 2 批量回测**。

离线样本内（2026-09-10）：风险平价夏普 **0.20** vs 等权 **-0.07**，样本内模拟，不是收益承诺。

公网链接见同目录 `DEMO_URL_待填.txt`（AlphaQuant：https://gsym236998-alphaquant.ms.show）。QuantInsight 是另一场比赛，不要用那条链接。
