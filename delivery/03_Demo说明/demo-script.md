# AlphaQuant 演示脚本（按钮级）

用途：初赛/路演现场或录屏。按 **当前 UI 真实按钮名**。总时长建议 4–6 分钟；10 分钟路演可在 2:30 切入、5:30 切出。

前置：`.\scripts\dev.ps1` 已启动；浏览器 **http://localhost:3000**；数据源 = **离线演示（可断网）**。Ctrl+F5 一次。

## 逐步操作

| 时间 | 操作（真实按钮） | 口播 |
|------|------------------|------|
| 0:00 | 打开仪表盘 | AlphaQuant 是因子增强选股加风险平价配置的演示平台。当前是研发中的可运行产品，不是实盘交易。 |
| 0:15 | 点 **一键演示案例 1** | 案例 1：个人投资者 10 万元闲置资金。系统先做多因子选股，再用风险平价加权，最后给出 VaR 和压力测试。 |
| 0:50 | 指向「风险平价夏普 / 等权夏普」 | 这是样本内历史模拟，风险平价夏普是否更好以当场数字为准，不是未来收益保证。 |
| 1:10 | 侧栏点 **选股**，再点 **刷新选股** | 这里能看到十个以上因子、IC/IR 动态权重，以及衰减告警。 |
| 1:40 | 点 **回测** → **运行回测** | 四种策略、六项指标，含交易成本近似。 |
| 2:05 | 点 **组合** → **优化入选篮子**，再点 **加载 Brinson 归因** | 四种优化可切换。Brinson 把超额拆成配置效应和选择效应，数字可对账。 |
| 2:40 | 点 **风控** → **评估风险平价组合** | 历史模拟 VaR/CVaR 和极端窗口，不是监管报备口径。 |
| 3:00 | 点 **适当性** → **填入保守示例** → **提交问卷并匹配** | 创新点五：问卷分档以后要和风险平价、仓位、波动规则匹配。保守档对满仓风险平价会拦截，这是功能不是故障。 |
| 3:35 | 点 **填入平衡示例** 再提交 | 平衡档通常可以通过。审计日志只留时间和答案摘要，没有身份证。 |
| 4:00 | 点 **案例2** → **运行案例 2 批量回测** | 小型私募研究流程：批量回测加归因。名义本金 1 亿元是演示口径，不是我们已管理 1 亿。 |
| 4:40 | 点 **生成并导出风控报告** | 标准化风控报告是结构化 JSON，同时可导出到本地文本，方便研究留痕。 |
| 5:10 | 回到仪表盘 | 整条链路都在本机，断网也能演示。第三阶段才规划接大模型，现在没有。 |

## 10 秒切录屏预案

- 若 **一键演示案例 1** 转圈超过 8 秒：切预先录好的仪表盘录屏，口播「这是同一离线样本的回放」。
- 若图表空白：Ctrl+F5，再点对应主按钮。
- 若后端挂了：打开 http://127.0.0.1:8010/health ，重新跑 `dev.ps1`。
- 适当性拦截被误以为崩溃：立刻说「这是匹配拦截，下面改平衡示例」。

## 禁语清单（当场不能说）

- QuantInsight、永字资管、HS300 8.56%、任何 AFAC 编号
- 「已接入大模型」「已有 10 万用户」「年收入 500 万已实现」
- 「真·持仓 / 已下单 / 实盘成交」
- 「我们已管理 1 亿」
- 把离线合成样本叫做「真实行情」
- Streamlit 就是本赛产品
- 把演示数据当实盘、把回测当承诺
